    Sobre o catálogo

    O catálogo só aponta para os projetos. Nenhum deles distribui o jogo: quase todos exigem que você tenha sua própria cópia legal do original.

    A atividade vem da data do último commit de cada repositório. Projetos fora do GitHub aparecem como "sem dados" quando não é possível conferir.

    O uso de IA é o declarado pelas fontes. Quando nenhuma fonte informa, não há marca.
